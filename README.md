# MJ · 局域网麻将

简洁深色风格的四人浏览器麻将。主机运行服务，另外三位玩家连接同一局域网加入房间。无需账号、数据库、构建步骤或第三方依赖。

## 启动与加入

1. 主机电脑安装 [Node.js 18 或更高版本](https://nodejs.org/)。
2. 下载本仓库，在项目目录运行 `npm start`。Windows 用户也可以双击 `Start MJ.cmd`。
3. 主机打开 `http://localhost:3000`，输入昵称并创建牌桌。
4. 将服务窗口显示的局域网地址和六位房间号发给另外三位玩家。
5. 其他玩家连接同一个 Wi-Fi，打开该局域网地址，选择加入并输入房间号。
6. 四人都按 Ready 后，由房主按 Start 开局。刷新页面可在两分钟内回到原座位。

只有主机需要安装 Node.js。若 Windows 防火墙询问，请允许应用在专用网络通信。游戏期间保持主机和服务窗口运行。

## 玩法

- 使用 136 张基础牌：萬、筒、條各 1–9，東南西北、中發白；每种四张。不含花牌。
- 庄家 14 张，其余玩家 13 张；庄家先打出一张牌。之后轮流摸牌、打牌。
- 胡牌为四组順子或刻子，加一对将牌。支持自摸和胡别人打出的牌。
- 吃只能由打牌者的下家提出；碰、杠可由其他玩家提出。胡优先于杠、碰、吃；同优先级按座次顺序处理。
- 暗杠、补杠和明杠后会从牌墙补一张牌。所有可响应玩家都作出选择后才结算吃碰杠或继续摸牌。
- 牌墙摸空且无人胡牌时为流局。流局或胡牌后四人都按 Next hand 开始下一局，庄家轮换。

这是便于局域网休息时游玩的基础规则版，不含番种、点数、积分、七对、花牌或多家同时胡牌。牌局状态由主机服务端校验；房间数据保存在内存中，服务停止后清空。建议只在可信局域网内使用，不要把端口暴露到公网。

## 网络问题排查

- 加入者应打开服务输出的 `LAN` 地址，不要在另一台设备上使用 `localhost`。
- 确认主机防火墙允许 TCP 3000 端口通过专用网络。
- 访客 Wi-Fi 或路由器的 AP 隔离可能会阻止设备互相连接。
- 更改端口：PowerShell 中运行 `$env:PORT=3001; node server.mjs`。

## 项目结构

```text
server.mjs        HTTP 服务、房间与牌局状态
game.mjs          牌墙、判胡和吃碰杠选项
public/index.html 页面结构
public/style.css  响应式深色界面
public/app.js     牌桌渲染与交互
Start MJ.cmd      Windows 启动脚本
```
